Sequential Fourm

Librarian for the Sequential Fourm synthesizer.

This editor provides librarian support only — patch browsing, downloading, uploading, and file saving/loading. It does not yet provide a graphical patch editor.

Banks

The Fourm has 4 banks of 128 patches each:

  • U1 – User Bank 1 (writable)
  • U2 – User Bank 2 (writable)
  • F1 – Factory Bank 1 (read-only)
  • F2 – Factory Bank 2 (read-only)

SysEx

  • Manufacturer ID: 0x01 (Sequential)
  • Device ID: 0x3B (Fourm)
  • Program Dump: F0 01 3B 02 <bank> <prog> <data> F7
  • Edit Buffer: F0 01 3B 03 <data> F7

MIDI SysEx must be enabled in the Fourm's globals for patch dumps to work.
